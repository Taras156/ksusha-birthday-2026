ПРАЗДНИЧНЫЙ ФОТОАЛЬБОМ ДЛЯ КСЮШИ
==================================

1. Распакуй весь архив в отдельную папку.
2. Открой index.html двойным щелчком в Chrome, Яндекс Браузере или Edge.
3. Нужен именно весь каталог, а не один index.html: рядом с ним должны лежать content.js, app.js, style.css, папки media и thumbs.
4. На телефоне удобнее смотреть сайт по ссылке. Для этого можно загрузить ВСЮ папку в новый репозиторий GitHub Pages (или заменить файлы отдельного репозитория). Сайт полностью статический, без сборки и сервера.
5. Не загружай в публичный репозиторий фотографии без согласия людей на фото: GitHub Pages с публичным репозиторием сделает изображения общедоступными.

ЧТО ВНУТРИ
------------
- 28 открытых глав из твоего исходного архива, с оригинальными названиями, датами и историями;
- 180 фотографий (включая 2 переведённых из HEIC) и 2 видео;
- 2 главы, которые были помечены скрытыми в источнике, намеренно не добавлены;
- оригинальный архив не изменялся;
- фото оптимизированы для быстрой загрузки, полный исходный архив сохрани как резервную копию;
- избранное работает только в том браузере, где ты его отметил.

КАК МЕНЯТЬ ПОЗДРАВЛЕНИЕ
------------------------
Найди в index.html блок <article class="letter-paper">. Можно менять текст внутри тегов <p>, а подпись — внутри <div class="signature">.

КАК МЕНЯТЬ ДАННЫЕ АЛЬБОМОВ
---------------------------
В content.js хранятся все названия, даты, описания и пути к фотографиям.
Рекомендуется сначала сделать копию этого файла.

ВАЖНО: В альбоме нет трекеров, авторизации, платного контента и внешних API.
Видео открываются в современном браузере с поддержкой MP4.
